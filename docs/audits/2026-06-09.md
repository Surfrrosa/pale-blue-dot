# Audit Log: 2026-06-09

Foundational audit pass. The plan called for a light sweep here —
the repo is intentionally minimal (vanilla HTML/CSS/JS, no build, no
dependencies). PR: `audit/2026-06-09` → main.

## Shipped in this PR

**Onboarding (`/init`):**
- Added `CLAUDE.md`. Documents the four-phase animation sequence,
  the renderer architecture, the conventions (single-file CSS, ES
  modules, no build step, no transpilation, explicit aria-labels),
  the credits, and the deployment path.

**Browser/OS edge cases (`/thatsweird`) — reduced-motion in JS:**
- The CSS already had a `@media (prefers-reduced-motion: reduce)`
  rule killing CSS animations + transitions. **But the JS animation
  loop (parallax + dot pulse) ignored the user preference entirely.**
- `js/main.js` now reads
  `matchMedia('(prefers-reduced-motion: reduce)').matches` at
  startup and:
  - Skips `pixelRenderer.startParallax()` (stars stay static).
  - Holds the dot at a steady glow instead of breathing
    (`Math.sin(time * 0.0008)` removed from the calculation when
    the preference is set).
- The story still tells (boot sequence → reveal → audio play). What
  goes away is the continuous motion.

**Accessibility (`/a11y`):**
- Survey only. The site already does the work: every button has an
  explicit `aria-label`, decorative SVG paths are inside labeled
  buttons, `<html lang="en">` and `<title>` are set, the boot text
  reveals on the canvas don't trap focus. Nothing to add.
